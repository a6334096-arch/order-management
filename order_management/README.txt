訂單管理系統（Flask + SQLite + Bootstrap 5）

啟動方式（Windows）：
1. 解壓縮專案，開啟 CMD / PowerShell 並 cd 到專案資料夾
2. 建立虛擬環境：python -m venv .venv
3. 啟用：.venv\Scripts\activate
4. 安裝套件：pip install -r requirements.txt
5. 啟動：python app.py
6. 瀏覽器開啟：http://127.0.0.1:5000

管理員帳密：
帳號：admin
密碼：admin123

注意：Bootstrap 5 使用 CDN，因此頁面樣式需要網路連線載入。
